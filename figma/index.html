Seven mobile screens, a wide Gestures board, foundation colours and clickable navigation. Text, shapes and diagrams stay editable.

Download Figma import kit ↓

  1. Unzip the download.
  2. Open a design file in Figma Desktop. Choose Plugins → Development → Import plugin from manifest.
  3. Select manifest.json in the extracted folder, then run FREQ Source Import.
  4. Present the FREQ / Start a room flow to click through the screens.

Use Space Grotesk and IBM Plex Mono for the closest match. The importer uses Inter when a font is unavailable.

Prepared from rendered browser layouts and checked against the Figma Plugin API. Native Figma execution and visual review remain unverified. Screen navigation is linked; browser interactions are captured in their initial state.
