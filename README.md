# FREQ Prototype

Eight source-derived mobile HTML screens from the supplied FREQ.html artifact. Open index.html or serve this directory with python3 -m http.server 8000.

Start → Pair → Main. Main → Visualiser / Submit / Recap. Visualiser and Submit return to Main; Recap returns to Start. Taste and Gestures are available in the screen index.

The original page geometry, copy, inline artwork and navigation are preserved. Artifact-host scripts have been removed, bundled fonts extracted and link targets resolved locally. Some font subsets retain their original Google Fonts URLs. Keep FONT-LICENSES.txt with redistributed font files.

Static UI concept: no Bluetooth, account connection, actual music playback, gesture recognition, uploads or shared-room backend. Source elements without links remain static.

The figma folder contains a native-frame import plugin prepared from these screens. It has not been run in Figma and needs visual review there. Repository: https://github.com/porto-labs-xyz/freq-prototype. Design system: https://github.com/porto-labs-xyz/freq-design-system.
